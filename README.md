****My Blog – Personal Portfolio Website****

This project is my personal portfolio website built to showcase my professional experience, technical skills, and cloud engineering projects. The website highlights my work in AWS infrastructure, automation, and cloud-based solutions while also providing a modern and interactive user interface.

Technologies Used

React.js – Used to build a dynamic and component-based frontend.

JavaScript (ES6+) – Handles the logic and interactivity of the application.

Tailwind CSS – Provides responsive styling and modern UI design.

Framer Motion – Adds smooth animations and interactive transitions.

Git & GitHub – Version control and project hosting.

Features

Responsive modern UI design

Animated project sections

Interactive experience timeline

Skills and technologies showcase

Cloud engineering project highlights

Smooth scrolling and visual effects

Purpose of the Project

The goal of this project is to present my professional journey as a Cloud System Analyst and demonstrate my knowledge of cloud infrastructure, DevOps practices, and modern frontend development. It serves as a centralized platform where recruiters, collaborators, and peers can explore my work and technical capabilities.
